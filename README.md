# Impostor Futbolero

Juego de "impostor" con futbolistas de todas las épocas. Se juega pasando un solo celular: todos ven al mismo jugador secreto menos el impostor, que tiene que disimular.

## Cómo jugarlo

Abre `index.html` en el navegador. En VS Code, con la extensión **Live Server**: clic derecho en `index.html` → **Open with Live Server**.

## Archivos

- `index.html`: el juego (pantallas, estilos y lógica).
- `jugadores.js`: la lista de 200 jugadores del piloto. Para agregar uno, copia una línea y cambia los datos.
